I fixed a few issues in the original Schrödinger code. The main problem was that it tried to take the square root of $1 - V/E$ as a real number, which is negative for $V/E = 1.5$, causing `nan` values and a blank plot. I changed this part to use complex numbers so the calculation works correctly for the potential barrier. I also fixed the plotting code so the wavefunction could be passed to `PlotView`, allowed $ka$ to be specified from the command line, and added the option to save the plots. I tested `ka` = 0.5, 1.0, and 2.0, and found that the wave oscillations become more frequent as $ka$ increases, meaning the wavelength decreases and the wave frequency increases.
