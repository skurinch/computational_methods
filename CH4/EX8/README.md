Based on the results from the Lagrange interpolation in the last exercise, I used a cubic spline interpolation this time using `QatGenericFunctions/InterpolatingFunction.h`. The cubic spline gives much more stable behavior near the endpoints and avoids the undershooting I saw with the Lagrange interpolation. There is still some wobbliness in a few of the actual data points, which seems to come from the program I used to convert the data rather than the interpolation itself. In the saved image, the four curves correspond to the four photoreceptor types: 420 nm _(black)_, 534 nm _(blue)_, 498 nm _(red)_, and 564 nm _(green)_.
